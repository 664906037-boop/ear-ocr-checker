# EAR OCR Checker — Focused V3

เวอร์ชันนี้ออกแบบให้ค้นหาเฉพาะข้อมูล 3 รายการ:

- CONTAINER NUMBER
- SEAL NO
- BOOKING

## วิธีอ่านข้อมูล

1. อ่านข้อความที่ฝังอยู่ใน PDF ก่อน
2. หากยังไม่ครบ จะเรนเดอร์ PDF เป็นภาพความละเอียดสูง
3. OCR ภาษาไทยและอังกฤษหลายรอบ
4. ประมวลผลทั้งภาพต้นฉบับ ภาพเพิ่ม Contrast และภาพขาวดำ
5. ค้นหาค่าใกล้หัวข้อภาษาไทยและอังกฤษ
6. ค้นหารูปแบบ Container เช่น `AAAA1234567` ทั่วทั้งเอกสาร
7. แก้ OCR ที่สับสน เช่น O/0, I/1, S/5, B/8
8. ลบช่องว่างและขีดก่อนเปรียบเทียบ

## รองรับ

- PDF
- JPG / JPEG
- PNG
- WEBP
