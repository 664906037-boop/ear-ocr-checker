# EAR OCR Checker — ROI V8

เวอร์ชันนี้ไม่ OCR ทั้งหน้าแล้ว

## ตรวจเพียง 3 คู่
- File 1: CONTAINER NUMBER ↔ File 2: Container No.
- File 1: SEAL NO ↔ File 2: SEAL
- File 1: BOOKING ↔ File 2: Booking No.

## วิธีทำงานใหม่
1. ถ้าเป็นรูปถ่าย ระบบพยายามตรวจขอบกระดาษและแก้ perspective ด้วย OpenCV.js
2. กำหนด ROI (กรอบตำแหน่ง) ของ 3 ช่องตามแบบฟอร์มจริงทั้ง 2 แบบ
3. Crop เฉพาะกรอบนั้น
4. OCR เฉพาะ A-Z / 0-9 หลาย pass
5. เปรียบเทียบค่าทั้ง 2 เอกสาร
6. ถ้าไม่ตรง จะระบุชื่อหัวข้อที่ไม่ตรง
7. ในหน้าผลสามารถกด “ดูกรอบที่ระบบอ่าน” เพื่อตรวจว่า crop ถูกตำแหน่งหรือไม่

## ฟรี
ใช้เฉพาะไลบรารีใน Browser:
- Tesseract.js
- PDF.js
- OpenCV.js

ไม่มี API เสียเงิน

## ข้อสำคัญ
ROI ถูกปรับจากตัวอย่างเอกสารจริงที่ให้มา ดังนั้นควรถ่ายให้เห็นเอกสารทั้งแผ่นหรือใกล้เคียงกับตัวอย่าง
หาก “ดูกรอบที่ระบบอ่าน” แล้วกรอบไม่ตรงตำแหน่ง สามารถปรับค่า ROI ใน app.js ได้โดยไม่ต้องเปลี่ยนระบบทั้งหมด
